## Selected technical checks against primary documentation

These four documents were opened during this audit; the remaining source catalog is retained historical evidence, not a claim that every document was reopened.

- [PostgreSQL 18 WAL introduction](https://www.postgresql.org/docs/18/wal-intro.html), §28.3, read 2026-10-30 via web: log records reach durable storage before related page writes; recovery can redo updates missing from pages. The storageLayout film assumes this; the mission adds a separate log crash/replay companion.
- [NGINX HTTP load balancing](https://nginx.org/en/docs/http/load_balancing.html), methods/least-connected/weights/health checks, read 2026-10-30 via web: request scheduling is governed by a backend selection policy and health. This differs from the baseline synthetic shard-key trace, which the mission replaces with a distinct routing model.
- [Kafka 4.1 design](https://kafka.apache.org/41/design/design/), Consumer Position/Message Delivery Semantics, read 2026-10-30 via web: retained logs separate reading progress from retention; offset/effect coordination matters for processing guarantees. The baseline offsets model taught only independent positions; the mission now adds a distinct partition/group/commit/rebalance model. Fixed 4.1 edition, no claim it is current.
- [RFC 9113 §9.1.1](https://www.rfc-editor.org/rfc/rfc9113.html#section-9.1.1), read 2026-10-30 via web: HTTP/2 can reuse an authoritative server connection for multiple URI authorities, with additional valid-certificate checks for HTTPS. This disproves the categorical same-origin-only wording in web-request Q3.
