## Non-negotiables (award bar)

1. Every string and character line traces to `SITE` / resume / LinkedIn / GitHub / owner.
2. First-load JS for `/` ≤ 120 kB; world idle-fetched; sound only after opt-in.
3. No Google SV / sat / mesh; Aleph = OSM + AWS Terrain only.
4. Mobile-first compositions; `prefers-reduced-motion: reduce` = designed stills + straight cuts.
5. Portal = only loud cut; night film grade; no purple-glow cyber UI or hero dashboard clutter.
