Play to hire

Three original game concepts for a senior / SDE-2 full-stack engineer, from a teardown of 8 game portfolios with REA (Bruno Simon, Messenger by Abeto, Henry Heffernan, Igloo, Jesse Zhou, Paodao, Simone Andreotti, My Room in 3D). Every game portfolio we found is a menu in costume; these make the job itself the game: requests, caches, queues and incidents. Each greybox below is actually playable (keyboard or touch), uses sample content only, and has a "How it becomes 3D" panel describing the real build with free CC0 assets. The résumé is one tap away in all three.

Open-world · GTA-style · driving

On Call

The city is a production system. Districts are the stack (Edge, API Gateway, Services, Cache, Queue Harbour, Data Vault), traffic is live requests, incidents are missions, and your phone is the résumé.

  • Drive to a yellow marker → incident brief → race to the fix → "Mission passed" case study
  • Error budget and severity stars replace "wanted level"; GPS and minimap like the games
  • Phone: joystick steers by direction, tap the map to set GPS, Auto-drive

Retro handheld RPG · childhood

Save File

A pocket console in your hand. Walk a pixel town where every door is a project, NPCs are teammates, and the Incident Gym is a turn-based system-design battle. START opens the résumé.

  • D-pad, A/B, START, SELECT on screen and on the keyboard
  • Battles: pick the fix that matches the fault (cache, scale out, index, rollback) to earn skill badges
  • Real save to the browser; "Continue" when you return

Tower defense · strategy

Hold the Line

Keep the database alive. Place services (CDN, cache, rate limiter, queue, load balancer) along the path as waves of reads, writes and bots arrive. p99 latency is simulated; each wave ends with a postmortem that tells a project.

  • Tap a service, tap a tile; towers combo like real systems
  • Waves: morning traffic, product launch, bot attack, Black Friday
  • Portrait turns the path vertical; the tray sits under your thumb
