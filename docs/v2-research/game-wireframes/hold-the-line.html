Hold the Line: the 3D build

The greybox is flat. The real build is a tilted 3D board, like a tabletop.

Look (free, CC0)

  • Kenney Tower Defense Kit (remade v2) for terrain, paths and tower bases, re-skinned: each tower is a little server rack, CDN dish, cache vault, toll gate, harbour crane.
  • Requests are Kenney Car Kit vehicles (or Mini Characters) on the path; one instanced mesh for hundreds.
  • Soft studio light, tilt-shift depth of field, the database glows hotter as load climbs.

The part that is hard to clone

  • A real queueing model: arrival rates per wave, service times per tower, a database whose latency curve bends like a real one under load (p99 is computed, not scripted).
  • Towers synergise like real systems: a load balancer speeds its neighbours, a queue smooths write bursts, a CDN only helps static traffic.
  • Each wave is a story beat (morning traffic, launch, bot attack, Black Friday) and ends with a postmortem card that tells a project.

Phones

Tap only, no joystick. In portrait the path runs top to bottom; the tower tray sits under your thumb.

Recruiter path
